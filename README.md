# AROOTH.COM

Source code for the AROOTH.COM project.

## Git layout

This repository is configured so Git tracks only **`backend/`**, **`frontend/`**, and **`README.md`** (plus **`.gitignore`**). PDFs, internal task/prompt markdown, duplicate root tooling, and `temp_pdf_reader/` stay out of the remote.

## Structure

- `frontend/`: web frontend

## Getting started

```bash
cd frontend
npm install
npm run dev
```
